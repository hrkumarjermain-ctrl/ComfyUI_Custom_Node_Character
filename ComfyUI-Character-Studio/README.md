# Character Architect Studio

Full-screen character creator for the Character Architect node in ComfyUI.

## Install

1. Copy this whole `ComfyUI-Character-Studio` folder into `ComfyUI/custom_nodes/`.
2. Restart ComfyUI and reload the browser tab.
3. Drag `workflows/character_architect_krea2.json` onto the canvas.
4. Click **🎭 Open Character Studio** on the Character Architect node, or use the
   **Character Studio** tab in the left sidebar.

Requires the Character Architect node pack and the custom nodes the workflow uses
(ComfyUI Manager → *Install Missing Custom Nodes*). The full guide is in the repository
README: https://github.com/hrkumarjermain-ctrl/ComfyUI_Custom_Node_Character
